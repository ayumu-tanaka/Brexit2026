Purpose

This temporary note examines whether affiliate-level exit responses to the Brexit referendum differed between affiliates whose parent firms had only one UK affiliate in 2010 and affiliates whose parent firms had two or more UK affiliates in 2010.

The key idea is that parent firms with multiple UK affiliates may have more scope to reorganize within the UK after the referendum, for example by closing one affiliate while keeping other UK affiliates in place.

Caveat

This is a reduced-form heterogeneity exercise at the affiliate level. It does not directly observe whether resources from a closed affiliate were actually reallocated to other surviving UK affiliates within the same parent firm.

    ),
    .groups = "drop"
  )

Summary for the paper

In the baseline exit sample, 381 parent firms have at least one UK affiliate in 2010. Among them, 55 parent firms have two or more UK affiliates. The group of parents with one UK affiliate contains 326 parent firms, 689 affiliates, and 4134 affiliate-year observations. The group of parents with two or more UK affiliates contains 55 parent firms, 344 affiliates, and 2064 affiliate-year observations. For comparison, the group of parents with no UK affiliates contains 519 parent firms, 661 affiliates, and 3966 affiliate-year observations.

Event-study estimates by the number of UK affiliates

event_groups <- c("One UK affiliate", "Two or more UK affiliates")

event_parent_counts <- sample_composition %>%
  filter(uk_multi_affiliate_group %in% event_groups) %>%
  mutate(uk_multi_affiliate_group = factor(uk_multi_affiliate_group, levels = event_groups)) %>%
  arrange(uk_multi_affiliate_group)

event_samples <- split(
  exit_sample %>% filter(uk_multi_affiliate_group %in% event_groups),
  factor(
    exit_sample %>% filter(uk_multi_affiliate_group %in% event_groups) %>% pull(uk_multi_affiliate_group),
    levels = event_groups
  )
)

event_models <- lapply(
  event_samples,
  function(df) {
    feols(
      exitit ~ i(year, GBR, 2014) | year + AffiliateCode,
      data = df,
      vcov = ~country
    )
  }
)

extract_event_years <- function(model) {
  coef_names <- names(coef(model))
  as.numeric(sub(".*year::([0-9]{4}):GBR.*", "\\1", coef_names))
}

joint_test_pvalue <- function(model, years) {
  coef_names <- names(coef(model))
  test_terms <- coef_names[extract_event_years(model) %in% years]

  if (length(test_terms) == 0) {
    return(NA_real_)
  }

  b <- coef(model)[test_terms]
  V <- vcov(model)[test_terms, test_terms, drop = FALSE]
  V_inv_b <- tryCatch(
    solve(V, b),
    error = function(e) qr.solve(V, b)
  )
  wald_stat <- as.numeric(t(b) %*% V_inv_b)
  1 - pchisq(wald_stat, df = length(test_terms))
}

event_fit_stats <- tibble(
  uk_multi_affiliate_group = factor(names(event_models), levels = event_groups),
  N = sapply(event_models, nobs),
  pretrend_p = sapply(event_models, joint_test_pvalue, years = c(2010, 2012)),
  post_p = sapply(event_models, joint_test_pvalue, years = c(2016, 2018, 2020))
) %>%
  left_join(event_parent_counts, by = "uk_multi_affiliate_group") %>%
  arrange(uk_multi_affiliate_group)

plot_event_study <- function() {
  do.call(
    iplot,
    c(
      event_models,
      list(
        pt.join = TRUE,
        sep = 0.5,
        ref.line = 0,
        xlab = "Year (two-year intervals)",
        ylab = "Estimated effect on exit probability",
        main = "Affiliate-Level Exit Responses by the Number of UK Affiliates within Parent Firms",
        ci_level = 0.95,
        col = c("#1b9e77", "#d95f02"),
        pt.col = c("#1b9e77", "#d95f02")
      )
    )
  )

  legend(
    "topright",
    legend = legend_labels,
    col = c("#1b9e77", "#d95f02"),
    pch = 19,
    lty = 1:2,
    lwd = 1,
    bty = "n",
    title = "Parent UK-affiliate group"
  )
}

Interpretation

This note is intended as a feasibility check. If affiliates belonging to parent firms with multiple UK affiliates show a larger exit response, one possible interpretation is that parent firms may have had more scope to reorganize within the UK while preserving some UK presence.
