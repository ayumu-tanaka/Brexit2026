# 査読レポート：「海外に錨を下ろす：サンクコスト、資産特殊性、およびブレグジット英国からの日本企業子会社の撤退」

## 要旨

本稿は、英国とEUの将来的な経済関係に対する不確実性を高めた2016年のブレグジット国民投票後における、英国への日本のFDI（対外直接投資）の変化を分析している。そのために著者らは、参入サンクコストが市場参入の意思決定にどう影響し、ヒステリシスを引き起こすかを示す定式化された概念的フレームワークを構築している。日本親会社とその海外子会社に関する情報を記録した日系企業データを用いて、企業レベルのDiD（差分の差分法）および受入国レベルの合成DID（SDiD）モデルを多数推計している。主な結果は、国民投票後における他のヨーロッパ経済と比較した場合、日本企業子会社の英国からの撤退に有意な影響は見られないというものである。また、資産特殊性の低い産業ではこれらのセクターへの投資をより多く回収できるという事実と整合的に、差異的な撤退が実際に生じていたことも示している。

## 評価

現在の世界的な経済政策において極めて重要なテーマについて、よく書かれた本稿を読んで大変興味深く思った。経済統合の解消がFDIに与える影響に関するミクロ的エビデンスは、文献上驚くほど乏しい。このことと、用いられている興味深いデータおよび実証戦略を踏まえると、本稿は文献に大きな貢献をする好位置にあると思う。ただし、結果への信頼性を高め、その重要性を全体的に際立たせるためのコメントが多数ある。その意味で、現在の草稿は不十分であり、改訂によって大いに改善されると考える。以下のコメントはその一助となることを目的としている（順序に特別な意味はない）。

## コメント

**1. 実際のブレグジットではない。** 本稿は抄録においてさえも「ブレグジットの…への影響」といった表現を繰り返し使用しているが、この研究は我々が一般的に理解するような意味でのブレグジットそのものを扱ったものではない。ブレグジットが実際に起きたのは2021年であり、ここでの分析は2016年の国民投票を中心としている。分析期間中、英国企業はEUと自由に貿易を行うことができ、2016年以前と同じEU規制のもとにあった。著者らが実際に捉えているのは、英国がEUを離脱することが明らかになった後の、ブレグジットのタイミングおよび実際の形態に関する不確実性の影響であると考えられる。著者らはこの点をより正確に記述すべきであると思う。加えて、この点がこの期間に推計された結果が弱い理由を説明するかもしれない。

**2. 結果の順序と重要性。** 本稿はセクターを統合した「ヌル（帰無）」結果に焦点を当てた構成になっている。まず、様々な推計量とロバストネス・チェックを用いて、「ブレグジット」が日本企業子会社の撤退に与える効果は正であるが有意ではないことを示すセクター統合推計から始まっている。この結果は確かに興味深く、出版される「ヌル」結果の数を増やすことには賛成である。しかし、私が最も興味深いと思う結果——資産特殊性が重要であるということ——は論文の終盤で示されている。私の見解では、統合推計と資産特殊性の異質性の比較こそを最初の結果とし、次に「ブレグジット」がこれらのセクターでの撤退に対してロバストな影響を持ったことを示すことに焦点を当てるべきである。

**3. 統合推計の結果。** すべての推計は年別の結果を算出している。これは分析している推計値が基準期間に対する年別の差として解釈されることを意味する。これ自体は問題ないが、「ブレグジット」の処置後平均効果については何も語っていない。具体的には、著者らはイベント・スタディに加えて、典型的な統合DID結果も含めるべきである。これは2016〜2020年の効果を統合することで係数を推計することを意味する（著者らはより高い統計的検出力を得られる）。これを行う場合、年次データと隔年データを混在させないよう注意が必要であり、そうしないと成長率が混在してしまう。つまり、2010年、2012年、2014年、2016年、2018年、2020年のデータのみを含めるべきである。

**4. コントロール・グループとしてのEU。** 他のEU諸国は英国にとって良いコントロール・グループだろうか。私の推測では、そうではない。なぜなら多くの日本企業がブレグジットという言葉が辞書にもなかった時代に他のEU諸国に対応するために英国を選択しており（英国はEU内の相対的な規模に比して不均衡に大きな割合の子会社を持っていた）、この場合、一部の企業は「拠点を移し」他のEU諸国に落ち着いたかもしれない（例えば図1の2018年以降の英国とドイツの推移を参照）。EU域外の高所得国を含む結果、およびEU・非EU双方の高所得国を含む結果を追加することを提案する。

**5. 日本にとっての英国の重要性。** 英国がEU内で日本の多国籍企業にとって重要であることは明らかである。しかし、英国はそれらの全事業において重要なのだろうか。著者らはこの点を検証し、英国の重要性に依存したさらなる異質性効果を分析する好位置にあると思われる。全体的な活動における英国への関与の割合が小さい企業ほど、英国から撤退しやすかったのではないかと思われる。

**6. セクターの変動。** 著者らは子会社（あるいは親会社）のセクターに関する情報を持っているようである。異なるセクターはブレグジットへの露出度が異なる。財の分野では、ブレグジットが起きた場合により高い関税に直面する可能性があるセクターがある（例：Graziano et al., 2021）。サービスの分野では、異なる規制に直面する（例：Ahmad et al., 2022）[^1]。セクター間の「ブレグジット強度」の変動を利用して撤退への効果を識別することで、論文を強化できると思う。

**7. 企業レベル対集計レベルの効果。** ほとんどの推計は子会社レベルで行われている。これは、ほとんどの企業がコントロール・グループに対して撤退しない場合、効果は有意でない可能性が高いことを意味する。しかし、撤退する企業が大企業である可能性があり、英国と日本の両方でより大きな経済的影響をもたらすかもしれない。逆のケースもありうる。これらの構成効果に対処するため、2つの異なる戦略を提案する：
   - **a. セクターレベルの集計。** セクターレベルで子会社数を集計し、左辺に件数を置いたPPML回帰を推計する。上述のセクター変動を活用することが有益であろう。
   - **b. 雇用による加重。** 企業またはセクター（あるいはその両方）を雇用水準で加重する。

**8. 撤退を含むモデル。** モデルは概念的にすっきりしており、実証分析のフレームワークを提供するという役割を果たしている。しかし、FDIのこの側面をもう少し深く研究する機会を逃していると思う。具体的には、撤退（divestiture）を企業の選択変数として考慮すべきであると思う。参入・退出コストや経済・政策条件の変化確率を変化させる比較静学を加えることで、このセクションにさらなる関連性を付与することができる。

**9. 特定国に対するロバストネス。** 分析は高所得EU諸国を用いて行われている。これらはわずかな数の国しかないため、著者らは一国ずつ除外した場合にも結果がロバストであるかを確認すべきである。言い換えれば、結果を引き起こしている特定の国があるか？原則として、これ自体は特に問題ではないが、示されるべきである。

**10. 相互に排他的なサンプルを用いた参入と撤退の比較。** 参入結果は最後のサブセクションに置かれており、SDiD法を用いて算出されている。「ブレグジット」の参入への影響の分析は、撤退への影響の分析と同程度に重要であると思う。さらに、モデルセクションでも同様の重要性が与えられている。できることとしては、2010年に存在しない企業のサンプル（すなわち撤退サンプルの補集合）を用いて、このサンプルへの影響を推計することである。これらの企業が2010年以降「新規」であったという仮定のもとで、推計値は「新規参入」として解釈でき、撤退係数と比較することができる。原則として、絶対値では新規参入への影響が撤退への影響より強いと予想される。

**11. その他のコメント。**
   - **a.** 予備的分析において、図1の左右のグラフは国数と水準対成長率という2つの側面で異なっており、直接比較することができない。一つの次元のみを変え、もう一方を付録に回すことを提案する。
   - **b.** 推計結果を要約するすべてのグラフが、観測数やR²などの重要な情報を欠いている。点推計、標準誤差等を含む対応する表を付録に加えることを提案する。
   - **c.** 2010年に存在する子会社を選択することで、サンプルに残る企業と観測値の割合はどのくらいか？全体のどの程度を見逃しているのか？この第一次的な情報が容易に見つからなかった。
   - **d.** 雇用は論文の後半でコントロール変数として使用されており、補完を必要とする。観測値の観点から雇用の補完はどの程度行われているか？雇用データのない観測値を除外した結果も提示することは可能か？
   - **e.** SDiDのために算出されたウェイトを示す付録の表を含めてほしい。
