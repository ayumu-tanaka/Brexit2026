**修正内容（2箇所）**

**① `Est15_2x2DiD.Rmd`（根本的解決）**

`modelsummary` v1.4以降のデフォルトバックエンド `tinytable` は `tabularray` + `\num{}` 形式でLaTeXを出力するため `siunitx` が必要になります。`setup` チャンクで以下を追加し、バックエンドを `kableExtra` に切り替えます：

```r
library(kableExtra)
options(modelsummary_factory_latex = "kableExtra")
```

`kableExtra` は標準的な `booktabs` 形式を出力するため `siunitx` への依存が消えます。次回Rmdを再実行したときから有効です。
